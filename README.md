# QuizPulse v1.3.0 · Windows 桌面端定时答题助手

一款基于 **Tauri v2（Rust + Windows 原生 WebView2）+ React/Tailwind + SQLite** 构建的轻量级定时学习工具，专为长时间后台挂机、零卡顿弹窗、高颜值 UI 与科学记忆复习设计。

## v1.3.0 核心升级亮点

- **不放回轮次随机（Shuffle-Bag）**：支持「随机不放回（按轮洗牌）」「艾宾浩斯智能复习」「顺序逐题刷」三种模式切换；保证所有活跃题全部答满一遍后才自动开启下一轮重新洗牌，支持可选穿插到期错题与手动一键重新洗牌。
- **彻底修复 v1.0 隐蔽缺陷**：
  - 修复题库超过 500 题时导出静默截断问题，管理列表改为流畅分页，导出支持全量无上限。
  - 修复简答题点击「我答对意思了（算我过）」导致的双重记分、错题标记残留与连对清零问题（改为原地快照回滚更新）。
  - 修复跳过题目后死循环重弹问题（自动移至本轮末尾）。
  - 修复后台定时循环每秒同步锁库问题（改用 `RwLock` 内存态缓存，实现 0 锁库/0 磁盘读）。
  - 修复弹窗 `matchMedia` 主题监听器累积泄漏与高分屏任务栏裁切（改用 `monitor.work_area()`）。
  - 修复切换数据目录潜在文件锁冲突（改用 SQLite 原生 `VACUUM INTO` 安全快照迁移）。
- **高颜值 UI 与极致减负交互**：
  - 弹窗高度随内容动态自适应（`380px ~ 680px`），实体高对比卡片与原生 Windows 11 Mica 透明主窗口。
  - **软件内单题新建与行内快编**（含可视化简答采分点 Tag 标签组编辑器），支持在弹窗批改后 5 秒顺手修错别字或补关键词。
  - **专注刷题 / 错题突击模式**、**90 天学习热力图**、**各题库掌握度进度条**、**单选题一键秒交**、**Web Audio 轻柔提示音**。
  - **全局快捷键（默认 `Alt+Q`）**随时呼出抽题；**智能系统托盘**实时悬停显示倒计时与轮次进度，支持动态暂停/恢复与「一键勿扰 1 小时」。

## Windows 本地一键打包

1. 安装 **Node.js 18+** 与 **Rust 工具链**（含 Visual Studio C++ Build Tools）。
2. 双击运行 **`build-windows.bat`**，或推送 `v1.3.0` 标签由 GitHub Actions 自动构建 `.exe` / `.msi` 安装包。
