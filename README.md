# QuizPulse · Windows 桌面端定时答题助手

一款基于 **Tauri v2（Rust + Windows 原生 WebView2）+ React/Tailwind + SQLite** 构建的轻量级定时学习工具，专为长时间后台运行、零卡顿弹窗、高颜值 UI 与科学记忆复习设计。

## 一、核心架构与防卡顿 / 低资源设计

| 维度 | 工程落地策略 |
| :--- | :--- |
| **极低后台内存** | 双窗口隔离：**主管理面板 (`main`) 按需创建、关闭即销毁 WebView 释放内存**；**答题弹窗 (`popup`) 独立轻量入口、预加载隐藏常驻**，后台仅运行 1 个 Rust 异步定时循环，常驻占用远低于 Electron。 |
| **零卡顿 / 零“未响应”** | 所有 SQLite 读写与 Excel `.xlsx` 解析/导出均通过 `tokio::task::spawn_blocking` 隔离到后台线程池；导入大题库走单事务批量提交，UI 线程永不阻塞。 |
| **防资源泄漏** | 全局单实例锁（`tauri-plugin-single-instance`）防重复启动；弹窗关闭拦截改为 `hide()` 复用窗口；前端所有 `listen()` 与 `keydown` 均严格在 `useEffect` cleanup 中注销。 |
| **原生勿扰与闲置暂停** | 调用 Windows `SHQueryUserNotificationState` 自动识别全屏游戏、PPT 投屏、会议与锁屏；调用 `GetLastInputInfo` + `GetTickCount`（无符号回绕安全）识别键鼠闲置超过阈值自动暂停，回归时自动保留 2 分钟缓冲，绝不堆叠弹窗。 |
| **艾宾浩斯与已通关流转** | 内置 8 阶复习间隔（30分 / 4时 / 12时 / 1天 / 2天 / 4天 / 7天 / 15天）；答错自动归零并 20 分钟后高频复现；连续答对达标自动进入「已通关题库」，也支持弹窗内一键手动通关或随时移回复习队列。 |
| **Excel 无损增量更新** | 导出的 `.xlsx` 模板自带 `ID` 列与下拉数据校验。新增题目时留空 `ID`；修改旧题并重新导入时保留原 `ID`，系统原地更新题干/关键词而不丢失艾宾浩斯复习进度与通关状态。 |

## 二、Windows 本地一键打包为 `.exe` / `.msi`

1. 确保电脑已安装：
   - **Node.js 18+**：`https://nodejs.org/`
   - **Rust 工具链**：`https://rustup.rs/`（安装时按提示勾选 Visual Studio C++ Build Tools）
2. 解压本工程目录后，直接双击运行 **`build-windows.bat`**（或在终端执行 `npm install && npm run tauri build`）。
3. 编译完成后，安装包位于 `src-tauri/target/release/bundle/nsis/`（`.exe` 安装包）与 `bundle/msi/`（`.msi` 安装包）。

> 日常开发调试可执行：`npm run tauri dev`

## 三、标准 Excel 题库模板说明

工程内 `templates/QuizPulse_题库标准模板.xlsx` 已附带可直接编辑的示例模板，也可在软件内点击「导出空白模板」或针对单个题库点击「导出编辑」。

- **题型**：下拉选择 `单选`、`多选`、`填空`、`简答`。
- **多选标准答案**：填字母组合如 `ABD`。
- **填空标准答案**：多空用分号 `;` 隔开，单空同义答案用斜杠 `/` 隔开（如 `TCP/传输控制协议;UDP/用户数据报协议`）；`多空不限顺序` 选 `是` 即可不限制各空作答顺序。
- **简答采分关键词**：不同采分点用分号 `;` 隔开，同一采分点的同义词用斜杠 `/` 隔开（如 `三次握手/3次握手;流量控制/滑动窗口`）。弹窗批改时会自动高亮命中/遗漏点，并提供「我答对意思了（算我过）」手动兜底按钮。

## 四、快捷键速查（答题弹窗）

- `1` ~ `6`：快速勾选单选 / 多选选项
- `Enter`：提交答案 / 进入下一题 / 完成本轮
- `Ctrl + Enter`：简答题文本框内快速提交
- `Esc`：一键延后提醒
